# Смета за 5 минут

Веб-приложение для быстрого составления смет и коммерческих предложений с сохранением в PDF.

Приложение предназначено для:
- предпринимателей, которым нужно подготовить коммерческое предложение клиенту;
- офисных сотрудников, которым нужно составить смету закупки или расходы для руководителя.

## Файлы приложения

- `index.html` — структура страницы: поля, список позиций, итоговая сумма и кнопки.
- `styles.css` — оформление страницы, удобные размеры элементов и адаптация для телефона.
- `script.js` — обработка ввода, расчёт стоимости и сохранение документа в PDF.

Сейчас созданы только `README.md` и `AGENTS.md`. Файлы приложения будут добавляться по отдельным запросам.

## Как открыть

После создания файлов приложения дважды щёлкните по `index.html`, чтобы открыть его в браузере. Установка программ и запуск сервера не требуются.

## Как проверить

После реализации расчётов добавьте две позиции:

1. Количество — 2, цена — 15 000 ₸.
2. Количество — 1, цена — 8 000 ₸.

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.
